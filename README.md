# Fort-Star Lubricants Hub

Official website for **Fort-Star Energy Resources Nigeria Limited** — a lubricant supply and energy solutions company serving industries across Nigeria.

**Live site:** https://fortstarenergy.com *(pending deployment — currently hosted at [fortstar-lubricant-hub.lovable.app](https://fortstar-lubricant-hub.lovable.app))*

## About the project

This site was built with [Lovable](https://lovable.dev/) and showcases Fort-Star's lubricant product range, company information, and a quote request flow for bulk/industrial customers.

### Sections
- **Home** — company intro and highlights (certified products, reliable delivery, quality assurance, wide range)
- **Lubricants** — product categories: engine oils, hydraulic oils, industrial greases
- **About** — company background
- **Contact** — company address, phone, and email
- **Request a Quote** — form for bulk lubricant supply inquiries

## Tech stack

- [TanStack Start](https://tanstack.com/start) — full-stack React framework with file-based routing and SSR
- TypeScript
- [Bun](https://bun.sh/) — package manager and runtime

## Project structure

This project uses **TanStack Start's file-based routing**. Every `.tsx` file inside `src/routes/` defines a route automatically.

> ⚠️ Do not create `src/pages/`, `src/routes/_app/index.tsx`, or `app/layout.tsx` — those are Next.js/Remix conventions and don't apply here. The single root layout lives at `src/routes/__root.tsx`.

| File | URL |
|---|---|
| `index.tsx` | `/` |
| `about.tsx` | `/about` |
| `users/index.tsx` | `/users` |
| `users/$id.tsx` | `/users/:id` (dynamic segment — bare `$`, no curly braces) |
| `posts/{-$category}.tsx` | `/posts/:category?` (optional segment) |
| `files/$.tsx` | `/files/*` (splat — read via `_splat` param, never `*`) |
| `_layout.tsx` | layout route (renders children via `<Outlet />`) |
| `__root.tsx` | app shell — wraps every page; preserve `<Outlet />` |

`src/routeTree.gen.ts` is auto-generated by TanStack Router. **Do not edit it by hand.**

## Development

You'll need [Bun](https://bun.sh/) installed.

```bash
git clone https://github.com/Jascode16/fortstar-lubricant-hub.git
cd fortstar-lubricant-hub
bun install
bun run dev
```

This starts the local dev server (check the terminal output for the exact port/URL).
